Project: Web Server using Docker

This project demonstrates how to build and run a simple web server using Docker.

Technologies Used

- HTML
- Docker
- Nginx

Steps to Run

1. Build the Docker image:
   "docker build -t codealpha-webserver ."
2. Run the Docker container:
   "docker run -d -p 8080:80 --name codealpha-webserver codealpha-webserver"
3. Open your browser and visit:
   "http://localhost:8080"

Output

A simple website displaying the CodeAlpha DevOps Internship page.
